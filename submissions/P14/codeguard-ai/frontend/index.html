Project Objectives & Overview

CodeGuard AI is an academic compiler design system engineered to evaluate source code similarity at the syntactic and intermediate representation levels. By analyzing Abstract Syntax Trees rather than superficial character sequences, CodeGuard AI reliably detects algorithmic clones regardless of superficial alterations such as identifier renaming, formatting, commentary, or minor statement additions.

Built strictly as an educational and pedagogical instrument, the system explains why two pieces of code share structural patterns, exposing students and educators to foundational principles of compiler theory, lexical analysis, syntax trees, tree edit distances, and intermediate canonicalization.

AST vs. Concrete Parse Tree

In compiler frontends, the Concrete Parse Tree (CST) represents the full syntactic derivation tree matching the formal grammar rules, retaining punctuation (colons, commas, parenthesis) and grammar non-terminals.

The Abstract Syntax Tree (AST) condenses this graph by removing syntactic trivia and preserving only semantic operations (such as BinOp, If, For) and operand relations. Consequently, differences in whitespace, indentation style, and comments do not alter the AST topology whatsoever.

Taxonomy of Code Clones

Type-1: Exact Clones

Identical program fragments except for variations in whitespace, formatting, blank lines, and comments. AST natively generates 100% identical trees.

Type-2: Renamed / Parameterized Clones

Syntactically identical fragments where user-defined identifiers (variables, functions, parameters) or literal constants have been substituted. Solved by CodeGuard AI's AST Normalization.

Type-3: Near-Miss / Modified Statement Clones

Fragments with modified, inserted, or deleted statements. Detected via Subtree Hashing and Sequence Alignment ratios.

Type-4: Semantic Clones

Syntactically disparate algorithms that perform identical computational semantics (e.g. Iterative vs. Recursive Fibonacci). AST comparison identifies distinct syntax structures.

Mathematical Similarity Formula

CodeGuard AI implements a documented, deterministic multi-metric structural similarity formula:

AST_Similarity = (0.55 × Subtree_Dice) + (0.30 × Sequence_Alignment) + (0.15 × Node_Type_Jaccard)

Where Subtree_Dice = 2 × |Subtrees(A) ∩ Subtrees(B)| / (|Subtrees(A)| + |Subtrees(B)|) evaluated on multiset subtree structural signatures.

Ethical & Academic Notice

This system is designed for compiler design education and code quality research. High structural similarity flags potential code cloning, but does not definitively prove intentional plagiarism. Legitimate reasons for structural convergence include standardized algorithmic templates, boilerplate framework code, and instructor-provided starter skeletons.
